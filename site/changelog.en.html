v2.2.0 2026-09-26 current

Xiaoyun enters the runtime

The mascot is no longer only a README illustration; it is a runtime asset shared by the CLI, logs and the Admin surface.

  • canal-common becomes the single source: PET_NAME, CANAL_CRAB ASCII, PET_SVG and banner().
  • New canal-rust pet subcommand; canal-rust --help and server startup logs print Xiaoyun.
  • Admin API landing page GET / shows Xiaoyun and live status; GET /pet.svg serves the vector original.
  • CI / Docker install protoc; 389 unit / integration tests pass, 0 Clippy warnings.
main 2026-10-28 unreleased

Expression fixes and asset license

  • Expression forms fixed: expression circles and duplicated facial features removed; all 12 keep their motion.
  • Mascot, images and expressions are explicitly non-open-source visual assets; commercial use needs written permission.
  • Latest commit on main; no version tag yet.
