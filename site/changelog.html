v2.2.0 2026-09-26 current

小运进入运行时

项目宠物不再只是 README 里的插图，而是 CLI、日志与管理端共同使用的运行时资产。

  • canal-common 成为唯一真源：PET_NAME、CANAL_CRAB ASCII、PET_SVG 与 banner()。
  • 新增 canal-rust pet 子命令；canal-rust --help 欢迎信息与 server 启动日志都会打印小运。
  • Admin API 落地页 GET / 展示小运与实时状态，GET /pet.svg 直接返回矢量原图。
  • CI 与 Docker 构建显式安装 protoc；389 项单元 / 集成测试全部通过，Clippy 0 警告。
