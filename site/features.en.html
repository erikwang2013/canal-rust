01 / MAP

The capability map.

Fourteen capabilities map one-to-one to 14 crates, in four groups: ingest, processing, egress, and operations. Ingest and processing decide what you can get; egress and operations decide how far it goes and how clearly you can see it.

02 / CAPABILITIES

Four groups,
each a stretch.

From the MySQL master to a client or Kafka, each crate has a clear place in the path. The groups follow data flow, not directory layout.

Ingest

01 — 03

canal-binlog

Connects to MySQL 5.1–8.0 / MariaDB, pulls binlog and maps TableMap into a unified event model.

mysql_cdc · position / GTID

canal-proto

Reuses upstream Canal .proto and generates Rust types with prost-build for wire compatibility.

CanalProtocol.proto · EntryProtocol.proto

canal-meta

Tracks DDL changes and caches table schemas so the parser does not query the master each time.

DDL tracking · schema cache

Processing

04 — 06

canal-filter

Regex-based table/schema include and exclude filters keep unwanted changes out of the path.

EventFilter · regex

canal-sink

Event fan-out: one change can enter the ring buffer and multiple connectors at once.

fan-out · Arc

canal-store

An in-memory ring buffer keeps events, evicts on overflow, and advances the position after client Ack.

VecDeque · ack

canal-client

Rust client SDK; subscribe to events and consume them as a stream.

04 / LIMITS

Know the edges,
then decide how to use it.

These limits come from upstream dependencies or defaults; they are not hidden traps. Check each one before deployment, especially plaintext MySQL and the Admin bind address.

Security

MySQL connections are plaintext

Upstream mysql_cdc 0.2.1 has no TLS and panics on any SslMode other than Disabled. Credentials and binlog data are unencrypted; use a trusted network or an SSH tunnel.

Auth

Limited auth plugins

Only mysql_native_password and caching_sha2_password are supported. An account using sha256_password will fail; create the account with an explicit plugin.

Bind

Admin is local by default

Without server.admin_bind, the Admin API is fixed at 127.0.0.1:{port+1}. Containers and remote clients need an explicit bind and firewall protection.

Metrics

/metrics has no auth by default

The metrics endpoint warns when no authentication is configured. It binds to loopback by default; if exposed, keep it on a private network or behind an authenticating proxy.

See Installation and Usage for the full security and deployment notes.
